# Bundled typefaces

All three families are published under the SIL Open Font License 1.1 and are
served from this folder so the game needs no font CDN.

| File | Family | Copyright |
|---|---|---|
| `space-grotesk.woff2` | Space Grotesk (variable, latin subset) | Florian Karsten |
| `jetbrains-mono.woff2` | JetBrains Mono (variable, latin subset) | The JetBrains Mono Project Authors |
| `silkscreen-400.woff2`, `silkscreen-700.woff2` | Silkscreen (latin subset) | Jason Kottke |

The complete OFL text: https://openfontlicense.org/open-font-license-official-text/

Copyright notices and the complete OFL 1.1 are also bundled locally:

- [Space Grotesk](Space-Grotesk-OFL.txt), from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/spacegrotesk/OFL.txt).
- [JetBrains Mono](JetBrains-Mono-OFL.txt), from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt).
- [Silkscreen](Silkscreen-OFL.txt), from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/silkscreen/OFL.txt).
