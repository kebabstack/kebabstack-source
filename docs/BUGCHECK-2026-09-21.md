- Company sign-in shows a compact progress state from the initial HTML through ticket verification, then enters the app. Actual failures reveal retry. Deep links and authorization checks remain.
- Contracts uses aligned SVG navigation icons instead of font-dependent symbols.
- Assets separates buyer invoice-receipt confirmation from physical hand-over. IT can finish a paid sale with an archived invoice and saved preparation checks even if its private link expired. Buyer confirmation is never fabricated. Existing admin, custody, Apple release and newer-sale checks remain enforced.
- Watch parses large certificate-log responses without constructing deep text ropes, preserves last successful evidence on failure, backs off for three hours and records recovery. Retry scheduling survives upgrades. Labels distinguish certificate-log evidence from a live TLS certificate test.
- Shared JSON sanitation preserves escaped backslash literals. The Hub uses that same implementation and keeps individual Okta pull-sync records flat, including large profile fields.

## Operator and company workflow

Reload after rollout. On a paid sale, save the wipe and company-management checks, resolve any Apple release confirmation, and record hand-over only when the buyer receives the device. External certificate-log availability remains an operational dependency.
